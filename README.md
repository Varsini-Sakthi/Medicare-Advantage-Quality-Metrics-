# Medicare Advantage Quality Metrics Dashboard

Quarterly HEDIS measure tracking and CMS Star Ratings simulation for a Medicare Advantage plan, built to demonstrate quality-improvement analytics: measure-level rate tracking, CMS star-banding logic, weighted domain roll-ups, and QI prioritization.

## Overview

This project simulates how a Medicare Advantage plan's quality analytics team tracks HEDIS/CAHPS/HOS performance between annual CMS Star Ratings submissions. It covers:

- **25 measures** across all 5 CMS Part C Star Ratings domains
- **CMS measure weighting** (1× standard, 3× for select outcome measures)
- **Star cut-point banding**, converting raw measure rates into 1–5 star values
- **Weighted roll-ups** at the domain and overall-plan level
- **Quarter-over-quarter trend tracking**, the way plans monitor rolling interim rates as leading indicators ahead of the annual HEDIS submission

## Data Model

**Domains:** Staying Healthy · Managing Chronic Conditions · Member Experience (CAHPS) · Complaints & Access Problems · Health Plan Customer Service

| `hedis_measures_quarterly.csv` column | Description |
|---|---|
| `quarter` | Rolling 12-month interim measurement period (e.g. `2021Q1`) |
| `measure` | HEDIS/CAHPS/HOS measure name, modeled on CMS's published Part C measure set |
| `domain` | One of 5 CMS Star Ratings domains |
| `weight` | CMS measure weight, 1× standard, 3× for select outcome measures |
| `eligible_denominator`, `numerator` | Simulated eligible population and compliant count |
| `rate` | `numerator / denominator`, as a percentage |
| `measure_star` | 1–5 star value derived from `rate` via `star_cut_points.csv` |

## Building the Tableau Version

The CSVs are structured to drop straight into Tableau Public (free, macOS-compatible):

1. **Connect** → Text File → `hedis_measures_quarterly.csv` (add `star_ratings_summary.csv` as a second source)
2. **Key calculated fields:**
   - Weighted star contribution: `[Measure Star] * [Weight]` → roll up as `SUM([Weighted Star Contribution]) / SUM([Weight])`
   - QoQ rate change: `[Rate] - LOOKUP(AVG([Rate]), -1)` (table calc, computed using `Quarter`, partitioned by `Measure`)
3. **Sheets:** overall trend line, domain breakdown bar/slope chart, measure detail table (colored by star threshold), KPI summary tiles
4. **Dashboard:** 1200×800, with a filter action from the domain chart into the measure table
5. **Publish** to Tableau Public for a shareable URL

## Methodology & Limitations

This project uses **fully synthetic data**, generated by a documented, reproducible script, not real plan, member, or CMS data.

- Star cut points are held **static across the 3-year window** for clarity. In practice, CMS re-clusters cut points annually via a hierarchical clustering algorithm (published in the Star Ratings Technical Notes), real thresholds shift year to year.
- "Real-time" / quarterly tracking refers to **rolling interim rate monitoring**, which is how plans commonly track performance between annual HEDIS submission cycles, HEDIS itself is calculated retrospectively from the prior measurement year's claims/chart-review data, not streamed live.
- Only **Part C measures** are modeled (no Part D drug measures), for a single hypothetical plan rather than a multi-contract book of business.
